# Awesome HOL Light

Find a route from an OCaml session to a reusable mathematical proof.

## Start here

- [HOL Light project](https://www.cl.cam.ac.uk/~jrh13/hol-light/) — Find installation guidance, reference material and the system's background.
- [Tutorial](https://www.cl.cam.ac.uk/~jrh13/hol-light/tutorial.pdf) — Work through goal-directed proofs and tactics before exploring larger theories.
- [Source and mathematical libraries](https://github.com/jrh13/hol-light) — Inspect library proofs and follow the checkout's README for compatible OCaml dependencies.

## First investigation

Follow a short tutorial proof and inspect the goal after each tactic. Record the HOL Light revision and OCaml version so another reader can repeat the session.

This is a suggested learning exercise. It has not been execution-tested by this collection.
